# NORTH DETAIL

Портфолио-концепт сайта премиальной студии детейлинга. Сайт создан на Next.js, React, TypeScript и Tailwind CSS. Все фотографии хранятся в проекте локально.

## Что нужно установить

- Node.js версии 20.9 или новее.
- pnpm или npm. В этом проекте рядом с зависимостями сохранён lock-файл pnpm.

## Запуск на компьютере

Откройте терминал в папке проекта и выполните команды по очереди:

    pnpm install
    pnpm dev

Первая команда устанавливает зависимости проекта, вторая запускает сайт для разработки. Откройте http://localhost:3000 в браузере.

Если вы используете npm, выполните вместо них команды `npm install` и `npm run dev`.

Чтобы остановить сервер, нажмите Ctrl+C в терминале.

## Production-сборка

    pnpm build
    pnpm start

Первая команда проверяет проект и собирает оптимизированную версию. Вторая запускает эту сборку локально на http://localhost:3000.

С npm команды будут `npm run build` и `npm run start`.

## Где редактировать сайт

- app/page.tsx собирает страницу из секций.
- app/layout.tsx задаёт общий макет, язык страницы и метаданные.
- app/globals.css подключает Tailwind и хранит общие цвета, типографику и небольшие эффекты.
- components/ содержит шапку, секции услуг, цены, галерею, студию, форму и подвал.
- public/assets/ содержит фотографии и значок сайта.

## Форма записи

Форма проверяет имя, телефон и выбранную услугу, но остаётся демонстрационной. Она не отправляет и не сохраняет введённые данные. Для настоящих заявок потребуется подключить сервер или сервис форм.

Цены, телефон и адрес электронной почты — демонстрационные данные. Галерея «до/после» помечена как визуальный пример, а не реальный результат работы с клиентом.

## Публикация

Проект можно развернуть на Vercel или другом хостинге с поддержкой Next.js. В панели хостинга подключите репозиторий, оставьте стандартные команды сборки Next.js и опубликуйте проект. Исходная HTML-версия сохранена в папке legacy-static/.
